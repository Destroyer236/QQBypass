# 检测点清单（由 smaliparse/findstr 从 smali 提取）

## gate —— 可直接 hook 返回正常值

| 类 | 方法 | 签名 | 正常值 |
|---|---|---|---|
| `oicq.wlogin_sdk.tools.util` | `isFileExist` | `(Ljava/lang/String;)Z` | false |
| `org.light.device.LightDeviceUtils` | `isRooted` | `()Z` | false |
| `com.tencent.gathererga.core.internal.provider.impl.UserInfoImpl` | `isRooted` | `(Lcom/tencent/gathererga/core/e;)Lcom/tencent/gathererga/core/f;` | Boolean.FALSE |
| `com.tenpay.charge.v2.util.ChargeV2Utils` | `isDeviceRooted` | `()Z` | false |
| `com.tencent.camerasdk.avreport.DeviceInfo` | `getDebugInfo` | `(Landroid/content/Context;)Ljava/lang/String;` | 干净字符串 |
| `com.tencent.qqperf.monitor.crash.c` | `c` | `(Landroid/content/Context;ZLjava/lang/String;Ljava/lang/String;Ljava/lang/String;IJLjava/lang/String;)Ljava/lang/String;` | isXposedInstalled: false |
| `com.tencent.mobileqq.qsec.qsecurity.QSec` | `detectMethod` | `(Ljava/lang/String;Ljava/lang/String;)Z` | false |
| `com.tencent.mobileqq.qsec.qsecurity.utils.ProcessCheck` | `isMainProcess` | `(Landroid/content/Context;)Z` | true |
| `com.tencent.mobileqq.qsec.qsecurity.utils.SocketStatus` | `checkSocket` | `(Ljava/lang/String;)I` | 非 1 |
| `com.tencent.mobileqq.qsec.qsecurity.utils.CertificationStatus` | `BL` | `([B)[Ljava/lang/Object;` | null 或正常状态数组 |
| `com.tencent.mobileqq.qsec.qsecurity.utils.SimpleAttestationParser` | `getBootStatus` | `(Ljava/security/cert/X509Certificate;)Lcom/tencent/mobileqq/qsec/qsecurity/utils/SimpleAttestationParser$BootStatus;` | verifiedBootState=0, isDeviceLocked=1 |

- **oicq.wlogin_sdk.tools.util.isFileExist**：w.h() 根检测的实际落点。对含 "su" 的路径恒返回 false 即可，副作用是 wtlogin 其他文件存在性检查也会被影响
- **org.light.device.LightDeviceUtils.isRooted**：遍历 5 个 su 路径，有 static Boolean isRooted 缓存（置过一次就不再检查）。hook 时连缓存字段一起改
- **com.tencent.gathererga.core.internal.provider.impl.UserInfoImpl.isRooted**：GatheredGA 设备指纹 SDK，InfoID=0x13c。遍历 10 个 su 路径 + Superuser.apk。返回 com.tencent.gathererga.core.internal.provider.c 对象，内部包 Boolean
- **com.tenpay.charge.v2.util.ChargeV2Utils.isDeviceRooted**：支付 SDK 的根检测（3 个 su 路径）。支付链路会读这个值
- **com.tencent.camerasdk.avreport.DeviceInfo.getDebugInfo**：拼接 ro.secure| / ro.debuggable| / tracer_pid| 上报。需返回不含这些标签的字符串，否则等于自报调试状态
- **com.tencent.qqperf.monitor.crash.c.c**：崩溃上报里拼 isXposedInstalled，用 PackageUtil.isAppInstalled 查 de.robv.android.xposed.installer。hook PackageUtil.isAppInstalled 更干净
- **com.tencent.mobileqq.qsec.qsecurity.QSec.detectMethod**：反射查方法存在性（反 Hook 原语）。★ 全包无调用方，是 QFix 预留空壳
- **com.tencent.mobileqq.qsec.qsecurity.utils.ProcessCheck.isMainProcess**：判断是否主进程。被 FEKit 调用，用于决定 QSec 是否初始化
- **com.tencent.mobileqq.qsec.qsecurity.utils.SocketStatus.checkSocket**：抽象命名空间 LocalSocket 探测（Magisk/Zygisk/Frida socket 手法）。★ 全包无调用方
- **com.tencent.mobileqq.qsec.qsecurity.utils.CertificationStatus.BL**：Android KeyStore 硬件密钥认证 + 证书链校验（EC/secp256r1/SHA-256/AndroidKeyStore）。异常时原生就返回 null
- **com.tencent.mobileqq.qsec.qsecurity.utils.SimpleAttestationParser.getBootStatus**：解析 Key Attestation 扩展（OID 1.3.6.1.4.1.11129.2.1.17），读 verifiedBootKeyHash。改 BootStatus 的5个字段

## probe —— 探测点（写 static 字段）

| 类 | 方法 | 签名 | 正常值 |
|---|---|---|---|
| `oicq.wlogin_sdk.request.w` | `h` | `()V` | - |

- **oicq.wlogin_sdk.request.w.h**：w.h() 里探测 /system/bin/su /system/xbin/su /sbin/su，结果写入 static int w.Y（1=有 su）。w.Y 会随 wtlogin 登录包上报。hook isFileExist 或直接改 w.Y

| 类 | 方法 | 签名 | 正常值 |
|---|---|---|---|
| `com.tencent.bugly.proguard.cp` | `<clinit>` | `()V` | - |

- **com.tencent.bugly.proguard.cp.<clinit>**：Bugly 的 18 条 su/后门路径检测表（含 cufsdosck / cufsmgr / conbb 等）。检测逻辑在 cp 的其他方法里，消费这张表

## crypto —— 签名原语（不是自校验）

| 类 | 方法 | 签名 | 正常值 |
|---|---|---|---|
| `com.tencent.mobileqq.qsec.qsecurity.QSec` | `getSign` | `(Ljava/lang/String;[B)[B` | - |
| `com.tencent.mobileqq.qsec.qsecurity.QSec` | `getSignEntry` | `(Ljava/lang/String;[B)[B` | - |

- **com.tencent.mobileqq.qsec.qsecurity.QSec.getSign**：签名原语入口 → ByteData.getSign → native。改包后这里返回的签名会不对，但它是「上报」不是「自校验」，不需要返回假值
- **com.tencent.mobileqq.qsec.qsecurity.QSec.getSignEntry**：按 QSecConfig.sign_strategy 分流 Lite/完整链路

## native —— 原生层（Java hook 够不着）

| 类 | 方法 | 签名 | 正常值 |
|---|---|---|---|
| `libQSec.so` | `JNI_OnLoad/定时器` | `-` | - |
| `libmatrix-memoryhook.so` | `HookManager` | `-` | - |

- **libQSec.so.JNI_OnLoad/定时器**：sigaction 抓 SIGTRAP/SIGSEGV + timer_create 周期自检 + dladdr 取自身基址。28KB 专职反调试壳，Java hook 完全够不着
- **libmatrix-memoryhook.so.HookManager**：Matrix 的 inline hook 扫描，会枚举常见 hook 框架的特征


### 关键「正常值」速查

| 检测项 | 正常设备（未 root） | 正常设备（未调试） | hook 应返回 |
|---|---|---|---|
| `w.Y`（wtlogin 根标记） | 0 | 0 | 0 |
| `isFileExist("...su")` | false | false | **false** |
| `LightDeviceUtils.isRooted()` | false | false | **false**（连缓存字段） |
| `UserInfoImpl.isRooted` | Boolean.FALSE | FALSE | **FALSE** |
| `ChargeV2Utils.isDeviceRooted()` | false | false | **false** |
| `getDebugInfo` 里的 `tracer_pid` | 0 | 0 | "0" 或不含该标签 |
| `getDebugInfo` 里的 `ro.debuggable` | 0 | 0 | "0" |
| `isXposedInstalled` | false | false | **false** |
| `QSec.detectMethod` | false | false | **false** |
| `ProcessCheck.isMainProcess` | true（主进程） | true | **true** |
| `SocketStatus.checkSocket` | 1（连不上） | 1 | **1** |

> 注意 `checkSocket` 返回 **1 才是"干净"**（连不上 = 没有框架监听）。
